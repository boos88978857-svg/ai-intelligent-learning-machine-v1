# ai-learning-machine-v1

AI 智能学习机（v1）

## 已完成
- Next.js App Router + TypeScript 基础架构
- 练习进度（Session）保存/读取/清除（localStorage）
- Debug 页面可建立测试进度
- Session 页面已接入涂鸦板（Whiteboard）：可打开/绘画/清除/关闭

## 测试入口
- 学习区：/practice
- Debug：/practice/debug（建立测试进度用）
- Session：从 /practice 点「继续」进入

## 目标（下一阶段）
- 最小题目闭环：出题 → 作答 → 判定对错 → 下一题
- 记录页：显示历史/统计
- 题库：英文/数学/其他
