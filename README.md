# AI 智能学习机（AI Intelligent Learning Machine）

## 📌 当前版本
**v1（Frozen / 结构冻结）**

本专案已完成 v1 最小可运行版本（MVP），  
核心目标为：**学习不中断、进度可续做、结构稳定**。

---

## 🎯 v1 已完成内容

### ✅ 学习不中断机制
- 作答过程中可刷新 / 断线 / 关闭网页
- 学习区可看到「未完成进度」
- 可选择「继续作答」或「清除进度」

### ✅ 作答流程（最小可跑）
- 进入作答页 `/practice/session`
- 计时（暂停 / 继续）
- 前进题目
- 记录对 / 错
- 提示次数计数

### ✅ 工具系统（基础）
- 涂鸦墙 Whiteboard
- 可开启 / 绘制 / 清除 / 关闭
- 不影响作答进度

---

## 🧱 v1 核心结构（冻结）
app/
├─ practice/
│   ├─ page.tsx              ← 学习区（续做中心）
│   ├─ session/
│   │   ├─ page.tsx           ← Server Wrapper
│   │   └─ SessionClient.tsx  ← 作答核心逻辑（禁止拆）
│   └─ debug/
│       └─ page.tsx           ← v1 测试用
└─ components/
└─ Whiteboard.tsx         ← 涂鸦墙组件
lib/
└─ session.ts                ← 进度逻辑唯一来源

⚠️ v1 冻结后禁止：
- 改档名
- 拆 SessionClient
- 在其他地方自行管理进度
